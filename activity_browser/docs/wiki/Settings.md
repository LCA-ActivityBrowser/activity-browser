# Settings

Open **Project > Settings...** to configure Activity Browser startup options.

## Interface language

Use the **Language** menu to choose one of the following options:

- **System default** uses Simplified Chinese on a Chinese-language system and
  English on other systems.
- **English** always uses the English interface.
- **Simplified Chinese** always uses the Simplified Chinese interface.

Save the settings and restart Activity Browser to apply a language change.

The language setting applies only to the Activity Browser interface. Scientific
database content, activity names, impact assessment methods, units, and exported
source data are not translated or otherwise modified.
